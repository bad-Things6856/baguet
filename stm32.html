⚡ STM32 Microcontroller

Overview

STM32 is a family of 32-bit ARM Cortex microcontrollers developed by STMicroelectronics. It is widely used in embedded systems, robotics, industrial automation, and IoT.

  • ARM Cortex-M core (M0, M3, M4, M7)
  • High performance (up to 480MHz)
  • Low power consumption
  • Rich peripherals

Popular Boards

  • STM32F103C8T6 (Blue Pill)
  • STM32F401CCU6
  • STM32F407 Discovery
  • STM32 Nucleo series

Applications

  • Robotics & automation
  • Flight controllers (drones)
  • Motor control
  • IoT devices
  • Medical electronics

Pin Functions (Example: STM32F103)

  • GPIOA, GPIOB, GPIOC → Digital I/O
  • ADC → PA0–PA7, PB0–PB1
  • UART → PA9 (TX), PA10 (RX)
  • I2C → PB6 (SCL), PB7 (SDA)
  • SPI → PA5, PA6, PA7
  • PWM → Most GPIO pins

Important Notes

  • 3.3V logic ONLY
  • Some pins are 5V tolerant
  • Use proper clock configuration
  • Boot0 pin selects programming mode

Development Methods

  • Arduino IDE (easy)
  • STM32CubeIDE (professional)
  • PlatformIO (advanced)

Install STM32 boards

Upload Methods

1. ST-Link (Recommended)

  • Connect SWDIO, SWCLK, GND, 3.3V
  • Use STM32CubeProgrammer

2. USB (Serial Bootloader)

  • Set BOOT0 = HIGH
  • Upload via USB
  • Set BOOT0 back to LOW

3. UART Upload

  • Use USB-TTL converter
  • TX ↔ RX connection

Basic Blink Code

void setup() {
  pinMode(PC13, OUTPUT);
}

void loop() {
  digitalWrite(PC13, LOW);
  delay(1000);
  digitalWrite(PC13, HIGH);
  delay(1000);
}

Serial Communication

void setup() {
  Serial.begin(9600);
}

void loop() {
  Serial.println("Hello STM32");
  delay(1000);
}

Pros

  • Very powerful
  • Cheap
  • Industrial grade
  • Flexible peripherals

Cons

  • Complex for beginners
  • Setup takes time
  • Documentation heavy

Tips

  • Always check pinout for your exact board
  • Use ST-Link for reliable upload
  • Use CubeIDE for advanced projects
  • Avoid wrong voltage (can damage MCU)
