⚡ ESP32-S3 XIAO

Overview

ESP32 is a powerful microcontroller with built-in WiFi and Bluetooth. It is widely used for IoT systems, embedded control, and automation projects.

  • Dual-core processor up to 240MHz
  • WiFi + Bluetooth (BLE)
  • Low power modes
  • Multiple GPIO pins

Applications

  • Smart home automation
  • Wireless sensor networks
  • IoT dashboards
  • Robotics
  • Wearables

Pin Functions

  • GPIO0–39 → Digital I/O
  • GPIO32–39 → ADC
  • GPIO25,26 → DAC
  • I2C → 21 (SDA), 22 (SCL)
  • SPI → 18,19,23,5
  • UART → TX (1), RX (3)

Important Notes

  • GPIO34–39 are input only
  • GPIO6–11 reserved
  • Boot pins must be used carefully

Basic Blink Code

void setup() {
  pinMode(2, OUTPUT);
}

void loop() {
  digitalWrite(2, HIGH);
  delay(1000);
  digitalWrite(2, LOW);
  delay(1000);
}

WiFi Example

#include <WiFi.h>

const char* ssid = "YOUR_WIFI";
const char* password = "PASSWORD";

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("Connected");
}

void loop() {}
