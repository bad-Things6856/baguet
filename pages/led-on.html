LED ON (Built-in)

This program turns ON the built-in LED on your Arduino board (usually connected to pin 13).

📌 How it works

- Set pin 13 as OUTPUT - Send HIGH signal → LED turns ON

💻 Code

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
}
